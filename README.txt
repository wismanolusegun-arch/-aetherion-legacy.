AETHERION: THE CREATOR'S LEGACY — WEBSITE STARTER

Files:
- index.html: website structure and content
- style.css: responsive fantasy theme and layout
- main.js: buttons and Three.js Elaris Village preview
- assets/aetherion-logo-banner.png: generated game banner/logo

OPEN ON IPHONE:
1. Extract Aetherion_Website_Starter.zip in the Files app.
2. Open the extracted folder and tap index.html.
3. If it opens in a preview instead of Safari, use Share > Open in Safari if available.
4. The 3D preview needs an internet connection and a browser that allows JavaScript modules/WebGL.

BEST WAY TO RUN:
For reliable local development, open this folder in Visual Studio Code on a computer and run it with Live Server. On iPhone, local file previews may restrict module imports; hosting the folder on a static website host is more reliable.

This is a starter website and simple 3D village preview, not the completed RPG. The prototype currently has a display scene and camera orbit; full character movement, quests, combat, saves and mobile controls are future development work.
